2026년 범서 테니스 클럽 운영 관리 앱

범서 테니스 클럽의 수입, 지출, 회원 명부 및 미납 내역을 투명하고 스마트하게 관리하기 위한 웹앱입니다.

## ✨ 주요 기능
* **장부 관리**: 수입/지출 내역 입력 및 월별 통계 확인
* **회원 명부**: 회원 정보 관리 및 전화 걸기 기능
* **미납 관리**: 미납 회원 확인 및 알림 문자 발송 기능
* **영수증 보관**: 영수증 사진을 업로드하여 체계적으로 관리
* **일정 관리**: 클럽 행사 및 회원 생일 달력 표시
* **결산 보고서**: 감사 보고서 및 결산 통계를 A4 서식으로 출력

## 🛠 사용 기술
* **Frontend**: HTML5, CSS3, JavaScript (Pretendard Font)
* **Database**: Firebase Realtime Database (실시간 데이터 동기화)
* **Libraries**: html2canvas, xlsx, Google Charts

## 📱 설치 및 실행 방법
이 앱은 설치가 필요 없는 웹앱(PWA)입니다.
1. 배포된 URL에 접속합니다.
2. 스마트폰의 브라우저 메뉴에서 **'홈 화면에 추가'**를 누르면 바탕화면에 앱 아이콘이 생깁니다.

## 🔑 관리자 권한
* 장부 입력 및 회원 정보 수정은 관리자 비밀번호를 통해 로그인이 필요합니다.
